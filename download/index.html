Rollback netplay for Tekken 5 Dark Resurrection on Windows. Free.

Download for Windows

Version 0.60.1 · 171 MB · Updates itself

View Project Backdash on GitHub

What you need

  • Windows 10 or 11, 64-bit
  • A CPU with AVX2Intel Core 4th generation or AMD Ryzen, or newer.
  • 8 GB of memory16 GB recommended. Below that, Low-end mode (1280 x 720).
  • Your own game filesTekken 5 Dark Resurrection Online for PS3: the .pkg or the game folder, with its .rap file. Never included.

If Windows warns you

The installer is not code-signed yet, so Windows may show Windows protected your PC. Click More info, then Run anyway.

More
  • The installer's SHA-256 is 082e012a34757dc4cf461819ed5996ad8ff8310e737bdaa75feb2a28a6ede589. To check it, run Get-FileHash "Project Backdash Setup 0.60.1.exe" in PowerShell.
  • With Smart App Control on (some Windows 11 PCs), there is no Run anyway, and Project Backdash cannot run there yet.
  • We never ask you to turn Windows security off, and never ask for game files, keys or payment.
